# XcaInteropService
XcaInteropService (Xca Interoperability Service) is a web service implementation of several IHE-profiles, mainly:  

* XCA Initiating Gateway
* Terminology server (Sharing Value Sets (SVS))
* Other services (in development)

## Solution Documentation

### [XCA Initiating Gateway](/Docs/XcaGateway.md)
The XCA Initiating gateway allows for Cross-community query and retrieve of documents and document metadata based on SOAP and IHE profiles.

### [Domain Configuration](/Docs/DomainConfig.md)
Describes the format and usage of the domain configuration

### [ValueSet/Terminology Server](/Docs/ValueSetTerminology.md)
Sharing of common concepts and values
