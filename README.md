# XcaInteropService
XcaInteropService (Xca Interoperability Service) is a web service implementation of several IHE-profiles, mainly:  

* XCA Initiating Gateway
* Terminology server (Sharing Value Sets (SVS))
* Other services (in development)

## Solution Documentation

### [🌐 XCA Initiating Gateway](/Docs/XcaGateway.md)
The XCA Initiating Gateway.

### [📝 Domain Config](/Docs/DomainConfig.md)
The domain config map used for querying other XCA Gateways.

### [📇 Value Set/Terminology Server](/Docs/ValueSetTerminology.md)
Value Set and Terminology server used for distributed sharing of value sets and codes.

### [📇 Patient Identity Management and Cross-Referencing](/Docs/PatientIdentity.md)
Patient identity management (PIX) solution for use when querying domains.
